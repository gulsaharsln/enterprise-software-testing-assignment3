# Enterprise Software Testing – Assignment 3

This project focuses on automated system testing of the [OpenCart Demo website](https://opencart.abstracta.us/) as part of our coursework at the University of Technology Sydney (UTS).

We used **JavaScript and TestCafe** to test 15 key functions, including product search, navigation, shopping cart operations, checkout, and account management.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/gulsaharsln/enterprise-software-testing-assignment3.git
```

Install dependencies:

```bash
cd enterprise-software-testing-assignment3
npm install
```

Run the tests:

```bash
npm test
```

Individual tests can also be executed using the scripts defined in `package.json`.

## Test Results

The group completed 45 test scenarios across 15 functions. All 45 scenarios passed in the final reported executions.

Detailed test cases, results, and findings are included in our System Test Report.
